# 三體星系模擬器

黑熊老師自然科學數位教材。三顆恆星與一顆行星以真實萬有引力逐步計算，行星氣候與城市文明在恆紀元與亂紀元之間興衰輪迴。

**線上使用：** https://prayer168.github.io/three-body-simulator/

## 功能
- 五種星系：三體世界、階層三星、太陽系對照、八字形編舞、隨機新星系
- 天象偵測：三日凌空、雙日凌空、三日連珠、飛星不動、兩顆／三顆飛星、長夜
- 行星溫度熱慣性、脫水與浸泡、文明九個時代、巨擺
- 從星系一路縮放到城市；仰望天空、巨擺、環繞視角
- 文明編年史、時間軸回放、混沌雙胞胎實驗
- 展示模式／教學模式（自動概念卡與課堂提問）
- Web Audio 即時合成的太空環境音

## 檔案
- `index.html`：可直接部署的單一檔案（Three.js r149 由 jsDelivr 載入）
- `src/`：原始碼（physics / audio / space / city / ui / page）
- `build.py`：把 `src/` 合併成單一 HTML

改編自劉慈欣《三體》的設定，數值為教學用簡化。
